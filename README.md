# Vlad Budko

Personal founder profile for Vlad Budko, Co-founder & CEO of GrowKong Group.

The site presents current companies, private operating systems, selected
business outcomes, and the ventures Vlad chose to close. It intentionally
contains no résumé, sales call-to-action, phone number, or job-seeking language.

## Local development

```bash
npm install
npm run dev
```

## Validation

```bash
npm test
```
